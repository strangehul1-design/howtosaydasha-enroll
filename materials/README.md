# Файлы с рекомендациями по уровням

Эти файлы Дарья отправляет ученикам после теста уровня: кнопка «📎 Отправить файл уровня …» в уведомлении открывает чат с учеником и подставляет в сообщение короткую ссылку на нужный файл.

| Результат теста | Файл |
|---|---|
| A1 и A2 | `howtosaydasha_Rekomendacii_A1-A2.pdf` |
| B1 | `howtosaydasha_Rekomendacii_B1.pdf` |
| B2 | `howtosaydasha_Rekomendacii_B2.pdf` |
| C1 | `howtosaydasha_Rekomendacii_C1-C2.pdf` |

Полная ссылка выглядит так: `https://strangehul1-design.github.io/howtosaydasha-enroll/materials/howtosaydasha_Rekomendacii_B1.pdf`. В сообщении ученику стоит её короткая версия (`https://clck.ru/…`), см. `SHORT_LINKS` в `worker/worker.js`.

## Как заменить файл

Положите новый PDF в эту папку **с тем же именем** и закоммитьте: ссылки останутся прежними (и полная, и короткая). Если имя меняется, поправьте его в `LEVEL_FILES` и создайте новую короткую ссылку для `SHORT_LINKS` в `worker/worker.js`, затем заново разверните воркер (`npx wrangler@4 deploy` в папке `worker`).

Репозиторий публичный, поэтому всё, что лежит в этой папке, доступно по прямой ссылке любому. Не кладите сюда то, что должно оставаться платным или закрытым.
