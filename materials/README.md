# Файлы по уровням

Сюда кладутся материалы, которые Дарья отправляет ученикам после теста уровня. Имена файлов должны быть ровно такими:

| Файл | Уровень |
|---|---|
| `A1.pdf` | Начальный |
| `A2.pdf` | Элементарный |
| `B1.pdf` | Средний |
| `B2.pdf` | Выше среднего |
| `C1.pdf` | Продвинутый |

Кнопка «📎 Отправить файл уровня …» в боте подставляет в сообщение ссылку вида
`https://strangehul1-design.github.io/howtosaydasha-enroll/materials/B1.pdf`.
Пока файла с таким именем нет, ссылка будет открывать ошибку 404.

Репозиторий публичный, поэтому всё, что лежит в этой папке, доступно по ссылке любому. Не кладите сюда то, что должно оставаться платным или закрытым.
