# Файлы с рекомендациями по уровням

Эти PDF бот присылает ученику вложением, когда тот проходит тест на сайте и нажимает Start в боте. Кнопка «📎 Отправить файл уровня … ещё раз» в уведомлении отправляет тот же файл повторно.

| Результат теста | Файл |
|---|---|
| A1 и A2 | `howtosaydasha_Rekomendacii_A1-A2.pdf` |
| B1 | `howtosaydasha_Rekomendacii_B1.pdf` |
| B2 | `howtosaydasha_Rekomendacii_B2.pdf` |
| C1 | `howtosaydasha_Rekomendacii_C1-C2.pdf` |

Ученик ссылок не видит: Telegram сам скачивает файл с сайта и присылает его вложением.

## Как заменить файл

Положите новый PDF в эту папку **с тем же именем** и закоммитьте. Если имя меняется, поправьте его в объекте `LEVEL_FILES` в `worker/worker.js` и заново разверните воркер (`npx wrangler@4 deploy` в папке `worker`). Размер файла не должен быть больше 20 МБ.

Репозиторий публичный, поэтому всё, что лежит в этой папке, доступно по прямой ссылке любому. Не кладите сюда то, что должно оставаться платным или закрытым.
