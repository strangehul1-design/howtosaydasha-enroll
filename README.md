# HowToSayDasha — запись на занятия

Мини-сайт онлайн-школы английского: прайс, преподаватель, отзывы, тест уровня, конструктор урока и форма записи.

## Что где лежит

| Путь | Что это |
|---|---|
| `index.html` | Весь сайт: HTML, CSS и JS в одном файле. Сборка не нужна, можно открыть в браузере. |
| `worker/` | Воркер для Cloudflare: «мозг» Telegram-бота и приём заявок с сайта. Инструкция в `worker/README.md`. |
| `materials/` | PDF с рекомендациями по уровням (A1–A2, B1, B2, C1–C2), которые бот присылает ученикам после теста. См. `materials/README.md`. |

## Как работает Telegram-бот

- **Тест уровня.** После теста ученик нажимает «Получить рекомендации в Telegram» и Start в боте. Бот сам присылает ему PDF его уровня вложением, а получателям приходит уведомление «@ник прошёл(а) тест на уровень …» с кнопками (отправить файл ещё раз, приветствие и вопрос о курсе, открыть чат).
- **Заявка «Соберите свой урок».** Приходит получателям одним сообщением.

Подробности и первая настройка: `worker/README.md`. Адрес воркера и имя бота прописаны в начале скрипта в `index.html` (`NOTIFY_URL`, `BOT_USERNAME`). Если оставить их пустыми, сайт предложит отправить заявку или результат вручную (почтой, Telegram или копированием).

## Что править

В скрипте в `index.html`:

- цены, форматы и описания программ: объект `PROGRAMS`;
- вопросы теста: массив `QUIZ` (по 4 вопроса на каждый уровень A1–C1; первый вариант в списке `o` — верный, при показе варианты перемешиваются), границы уровней: функция `levelFor`;
- контакты: `CONTACT_EMAIL`, `TELEGRAM_URL` и блок `<footer>`;
- отзывы и текст преподавателя: обычный HTML выше по файлу.

Фото преподавателя пока нет: вместо него буква в круге (`.avatar`).
