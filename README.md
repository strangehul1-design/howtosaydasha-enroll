# HowToSayDasha — запись на занятия

Мини-сайт онлайн-школы английского: прайс, преподаватели, конструктор урока и форма записи.

Весь сайт — один файл `index.html` (HTML, CSS и JS внутри). Сборка не нужна: откройте файл в браузере.

## Отправка заявок

В начале скрипта в `index.html` есть настройка:

```js
const FORM_ENDPOINT = '';
```

- Пусто — после нажатия на кнопку заявка собирается в текст, который можно отправить в Telegram, на почту или скопировать.
- Адрес (например, Formspree: `https://formspree.io/f/xxxxxxx`) — заявка уходит туда JSON-запросом.

## Что править

- Цены, программы и преподаватели — объекты `TEACHERS` и `PROGRAMS` в скрипте.
- Контакты — `CONTACT_EMAIL`, `TELEGRAM_URL` и блок `<footer>`.
- Фото преподавателей: сейчас вместо них буквы в кружках (`.avatar`).
