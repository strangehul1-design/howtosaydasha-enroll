# HowToSayDasha — запись на занятия

Мини-сайт онлайн-школы английского: прайс, преподаватель, отзывы, тест уровня, конструктор урока и форма записи.

## Что где лежит

| Путь | Что это |
|---|---|
| `index.html` | Весь сайт: HTML, CSS и JS в одном файле. Сборка не нужна, можно открыть в браузере. |
| `worker/` | Воркер для Cloudflare: пересылает заявки и результаты теста в Telegram-бота. Инструкция в `worker/README.md`. |
| `materials/` | PDF с рекомендациями по уровням (A1–A2, B1, B2, C1–C2), ссылки на которые Дарья отправляет ученикам после теста. См. `materials/README.md`. |

## Отправка в Telegram

В начале скрипта в `index.html` есть настройка:

```js
const NOTIFY_URL = '';
```

- **Пусто** — после нажатия на кнопку заявка или результат теста собираются в текст, который ученик отправляет сам: в Telegram, на почту или копированием.
- **Адрес воркера** — всё приходит в бота автоматически, как описано в `worker/README.md`.

**Как это работает для ученика.** После теста он оставляет на сайте только свой Telegram-ник, в бота заходить не нужно. Даше в бот приходит «@ник прошёл(а) тест на уровень …» с двумя кнопками: первая открывает чат с учеником и подставляет короткую ссылку на PDF его уровня, вторая подставляет приветствие и вопрос о курсе.

Версия, где бот сам отвечал ученикам (вход через Telegram, вебхук), сохранена в git под меткой `bot-flow`.

## Что править

В скрипте в `index.html`:

- цены, форматы и описания программ: объект `PROGRAMS`;
- вопросы теста: массив `QUIZ` (по 4 вопроса на каждый уровень A1–C1; первый вариант в списке `o` — верный, при показе варианты перемешиваются), границы уровней: функция `levelFor`;
- контакты: `CONTACT_EMAIL`, `TELEGRAM_URL` и блок `<footer>`;
- отзывы и текст преподавателя: обычный HTML выше по файлу.

Фото преподавателя пока нет: вместо него буква в круге (`.avatar`).
