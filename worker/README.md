# Уведомления в Telegram-бота

Сайт — статический, поэтому сам отправить сообщение в бота он не может: для этого нужен токен бота, а токен нельзя класть в код сайта (репозиторий публичный, любой смог бы им воспользоваться). Поэтому между сайтом и ботом стоит маленький воркер `worker.js` на Cloudflare: он хранит токен в секрете и пересылает в бота два вида сообщений.

| Что происходит на сайте | Что приходит в бота |
|---|---|
| Ученик прошёл тест уровня и оставил Telegram | `@username прошёл(а) тест на уровень B1`, счёт, разбивка по уровням и **две кнопки** |
| Ученик отправил форму «Соберите свой урок» | Вся заявка текстом и кнопка «Написать @username» (если он указал Telegram) |

## Кнопки под уведомлением о тесте

1. **📎 Отправить файл уровня B1** открывает личный чат с учеником. В поле ввода уже готово сообщение со ссылкой на файл его уровня (`materials/B1.pdf`). Вам остаётся нажать «Отправить».
2. **👋 Приветствие и вопрос о курсе** открывает тот же чат с готовым приветствием и вопросом, на какой курс ученик хотел бы записаться.

> **Ограничение Telegram.** Ссылкой нельзя прикрепить файл к сообщению, можно только подставить текст. Поэтому файл уровня отправляется как ссылка внутри сообщения. Чтобы кнопки открывали чат, ученик должен оставить Telegram-юзернейм (`@username`).

Тексты сообщений меняются в начале `worker.js` (объект `TEXTS`).

## Как подключить (один раз, ~10 минут, бесплатно)

1. **Нажмите Start в своём боте.** Пока вы его не запустили, бот не может вам писать.
2. **Узнайте свой Telegram ID.** Напишите боту [@userinfobot](https://t.me/userinfobot), он ответит числом `Id`.
3. **Создайте воркер.** Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com) (бесплатный тариф подходит), затем **Workers & Pages → Create → Create Worker**, имя `htsd-notify` → **Deploy** → **Edit code**. Удалите пример, вставьте содержимое `worker/worker.js` и нажмите **Deploy**.
4. **Добавьте настройки:** воркер → **Settings → Variables and Secrets → Add**:

   | Имя | Тип | Значение |
   |---|---|---|
   | `BOT_TOKEN` | **Secret** | токен бота из @BotFather |
   | `OWNER_CHAT_ID` | Text | число из шага 2 |
   | `ALLOWED_ORIGINS` | Text | `https://strangehul1-design.github.io` |
   | `SITE_URL` | Text | `https://strangehul1-design.github.io/howtosaydasha-enroll` |

   Нажмите **Deploy** ещё раз.
5. **Проверьте.** Откройте адрес воркера (`https://htsd-notify.<ваше-имя>.workers.dev`): должно появиться `{"ok":true,"service":"howtosaydasha-notify"}`.
6. **Впишите адрес в сайт:** в `index.html` найдите `const NOTIFY_URL = '';` и вставьте туда адрес воркера. Затем закоммитьте изменение.
7. **Положите файлы по уровням** в папку `materials/` (см. `materials/README.md`).

> **Токен никогда не вставляйте** в `index.html`, README или другие файлы репозитория и не присылайте в чаты. Он нужен только в настройках воркера (шаг 4). Если токен всё же попал куда-то лишний, в @BotFather выполните `/revoke` и подставьте новый.

## Защита от спама

Воркер принимает запросы только с адреса сайта (`ALLOWED_ORIGINS`), проверяет формат данных (уровень, юзернейм, размер запроса), экранирует текст и игнорирует заполненное скрытое поле-ловушку для ботов. Этого достаточно для небольшого сайта. Если начнётся спам, к воркеру можно добавить Cloudflare Turnstile.

## Проверка без интернета

```bash
node worker/test.mjs
```

Тест подменяет Telegram заглушкой и проверяет текст уведомлений, обе кнопки, ссылки и защиту.
