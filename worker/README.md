# Уведомления в Telegram-бота: воркер

Сайт статический, поэтому сам писать в Telegram он не может: для этого нужен токен бота, а токен нельзя класть в код сайта (репозиторий публичный). Между сайтом и ботом стоит воркер `worker.js` на Cloudflare: он хранит токен в секретах и пересылает в бота два вида сообщений. **Ученик в бота не заходит**, бот только присылает уведомления школе.

## Что происходит

| Что на сайте | Что приходит в бота |
|---|---|
| Ученик прошёл тест уровня и оставил свой Telegram-ник | `@username прошёл(а) тест на уровень B1`, счёт, разбивка по уровням и **две кнопки** |
| Ученик отправил форму «Соберите свой урок» | Вся заявка текстом и кнопка «Написать @username» (если он указал Telegram) |

### Кнопки под уведомлением о тесте

1. **📎 Отправить файл уровня B1** открывает личный чат с учеником. В поле ввода уже готово сообщение с короткой ссылкой на файл рекомендаций для его уровня (какой файл какому уровню соответствует, см. `materials/README.md`). Остаётся нажать «Отправить».
2. **👋 Приветствие и вопрос о курсе** открывает тот же чат с готовым приветствием и вопросом, на какой курс ученик хотел бы записаться.

> **Ограничение Telegram.** Ссылкой нельзя прикрепить файл к сообщению, можно только подставить текст. Поэтому файл отправляется как ссылка внутри сообщения. Чтобы кнопки открывали чат, ученик должен оставить Telegram-юзернейм (`@username`).

Тексты сообщений меняются в начале `worker.js` (объект `TEXTS`).

### Короткие ссылки

В сообщении ученику стоит короткая ссылка вида `https://clck.ru/3WeZqH` (22 символа вместо 100), которая открывает тот же PDF. Они созданы сервисом clck.ru и записаны в объекте `SHORT_LINKS` в `worker.js`. Если сервис когда-нибудь перестанет работать, очистите `SHORT_LINKS`: воркер вернётся к полным ссылкам. После замены PDF с тем же именем короткие ссылки продолжают работать. Для нового файла с другим именем создайте короткую ссылку (`https://clck.ru/--?url=<ссылка на файл>`) и впишите её.

## Секреты и настройки воркера

| Имя | Что это | Где хранится |
|---|---|---|
| `BOT_TOKEN` | токен бота от @BotFather | секрет Cloudflare |
| `OWNER_CHAT_ID` | Telegram ID получателей, несколько через запятую (`111,222`) | секрет Cloudflare |
| `SETUP_KEY` | ключ для служебных запросов (`POST /status`, `POST /setup`) | секрет Cloudflare |
| `ALLOWED_ORIGINS`, `SITE_URL` | адрес сайта | `wrangler.toml` |

> **Токен никогда не вставляйте** в `index.html`, README или другие файлы репозитория и не присылайте в чаты. Он нужен только как секрет воркера. Если токен попал куда-то лишний, в @BotFather выполните `/revoke` и задайте новый.

Секрет задаётся командой в папке `worker` (на Windows в PowerShell пишите `npx.cmd`, если появляется ошибка про выполнение сценариев):

```bash
npx wrangler@4 secret put BOT_TOKEN
```

**Добавить получателя.** Новый человек нажимает **Start** в боте, узнаёт свой ID у [@userinfobot](https://t.me/userinfobot), и вы задаёте `OWNER_CHAT_ID` со всеми ID через запятую. Перезапускать воркер не нужно.

## Первая настройка с нуля

1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com) и войдите: `npx wrangler@4 login`.
2. Разверните воркер: `npx wrangler@4 deploy` (в папке `worker`). Команда напечатает адрес вида `https://htsd-notify.<имя>.workers.dev`.
3. Задайте три секрета из таблицы выше (`secret put`). Для `SETUP_KEY` придумайте длинную случайную строку из латинских букв и цифр.
4. Впишите адрес воркера в `NOTIFY_URL` в начале скрипта в `index.html`.
5. Каждый получатель нажимает **Start** в боте, иначе Telegram не даст боту ему писать.

## Служебные запросы (по желанию)

```bash
curl -X POST https://htsd-notify.<имя>.workers.dev/status -H "X-Setup-Key: <SETUP_KEY>"
```

Показывает имя бота, сколько получателей настроено и состояние вебхука. `POST /setup` с тем же ключом выключает вебхук (остался от прошлой версии, где бот сам отвечал ученикам: её код сохранён в git под меткой `bot-flow`).

## Защита

- Данные принимаются только с адреса сайта (`ALLOWED_ORIGINS`), иначе ответ 403.
- Воркер проверяет формат (уровень, юзернейм, размер запроса), экранирует текст и игнорирует скрытое поле-ловушку для ботов.
- Токен хранится только в секретах Cloudflare.

## Проверка без интернета

```bash
node worker/test.mjs
```

Тест подменяет Telegram заглушкой и проверяет текст уведомлений, обе кнопки, ссылки и защиту.
