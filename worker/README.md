# Telegram-бот школы: воркер

Сайт статический, поэтому сам писать в Telegram он не может: для этого нужен токен бота, а токен нельзя класть в код сайта (репозиторий публичный). Между сайтом и ботом стоит воркер `worker.js` на Cloudflare. Он хранит токен в секретах и делает две вещи.

## Что происходит

**1. Тест уровня**

1. Ученик проходит тест на сайте и видит результат.
2. Он нажимает **«Войти через Telegram и получить рекомендации»**. Во всплывающем окне на сайте он подтверждает вход и разрешает боту школы писать ему. **Заходить в бота не нужно.**
3. Воркер проверяет подпись Telegram (чтобы никто не смог выдать себя за другого) и присылает получателям уведомление:

   > 🧪 **@username** прошёл(а) тест на уровень **B1** (Средний)
   > Правильных ответов: 12 из 20
   > По уровням: A1 4/4, A2 4/4, B1 4/4, B2 0/4, C1 0/4
   > Файл ещё не отправлен: нажмите кнопку ниже.

4. Даша нажимает **«📎 Отправить файл уровня …»**, и бот присылает ученику **PDF с рекомендациями его уровня вложением**, без ссылок. Файлы лежат в `materials/` (какой файл какому уровню соответствует, см. `materials/README.md`).

   Под уведомлением три кнопки:
   - **📎 Отправить файл уровня …**: бот присылает ученику PDF.
   - **👋 Приветствие и вопрос о курсе**: бот пишет ученику «Здравствуйте! Это Дарья из HowToSayDasha… На какой курс вы хотели бы записаться?» с кнопками выбора курса. Когда ученик нажимает курс, вам приходит «@username выбрал(а) курс: …».
   - **💬 Открыть чат**: открывает личную переписку с учеником (если у него нет юзернейма, откроется его профиль).

**Если окно входа не открывается.** Под кнопкой есть запасная ссылка: ученик открывает бота и нажимает **Start**. Тогда бот сразу сам присылает ему PDF, а получателям приходит то же уведомление. Если у ученика нет Telegram, он может отправить результат на почту или скопировать его.

**Если ученик не разрешил боту писать.** При нажатии кнопки Даша увидит подсказку «Ученик не разрешил боту писать. Нажмите «Открыть чат» и напишите ему сами». Telegram запрещает боту писать первым тем, кто этого не разрешал.

Всё, что ученик пишет боту (текст, фото, файлы), бот пересылает получателям с кнопкой «Открыть чат». Отвечать ученику нужно из своего аккаунта: нажмите «Открыть чат». Команда `/id` показывает Telegram ID того, кто её отправил (удобно, чтобы добавить получателя).

**2. Заявка «Соберите свой урок»**

Форма с сайта приходит получателям одним сообщением с кнопкой «Написать @username» (если ученик указал Telegram).

Тексты, которые бот отправляет ученикам, меняются в объекте `TEXTS` в начале `worker.js`.

## Секреты и настройки воркера

| Имя | Что это | Где хранится |
|---|---|---|
| `BOT_TOKEN` | токен бота от @BotFather | секрет Cloudflare |
| `OWNER_CHAT_ID` | Telegram ID получателей, несколько через запятую | секрет Cloudflare |
| `SETUP_KEY` | ключ для настройки и диагностики (`POST /setup`, `POST /status`) | секрет Cloudflare |
| `ALLOWED_ORIGINS`, `SITE_URL` | адрес сайта | `wrangler.toml` |

> **Токен никогда не вставляйте** в `index.html`, README или другие файлы репозитория и не присылайте в чаты. Он нужен только как секрет воркера. Если токен попал куда-то лишний, в @BotFather выполните `/revoke` и задайте новый (команда ниже).

Секрет задаётся командой в папке `worker` (на Windows в PowerShell пишите `npx.cmd`, если появляется ошибка про выполнение сценариев):

```bash
npx wrangler@4 secret put BOT_TOKEN
```

Это же способ добавить ещё одного получателя: новый человек нажимает **Start** в боте, узнаёт свой ID командой `/id` и вы задаёте `OWNER_CHAT_ID` со всеми ID через запятую (`111,222`). Перезапускать воркер не нужно.

## Вход через Telegram: настройка в BotFather (один раз)

Чтобы кнопка «Войти через Telegram» заработала, Telegram должен знать адрес сайта:

1. Откройте [@BotFather](https://t.me/BotFather), выберите бота, затем пункт **Login Widget** (в мини-приложении BotFather).
2. Добавьте в **Allowed URLs**: `https://strangehul1-design.github.io` и `https://strangehul1-design.github.io/howtosaydasha-enroll/`.
3. Проверьте **Client ID**: он должен совпадать с ID бота (число из токена до двоеточия, у нас `8613049237`). Если отличается, впишите его в `TELEGRAM_CLIENT_ID` в `index.html` и задайте секрет `LOGIN_CLIENT_ID` в воркере.

**Client Secret** из BotFather здесь не нужен, никому его не присылайте.

## Первая настройка с нуля

1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com) и войдите: `npx wrangler@4 login`.
2. Разверните воркер: `npx wrangler@4 deploy` (в папке `worker`). Команда напечатает адрес вида `https://htsd-notify.<имя>.workers.dev`.
3. Задайте три секрета из таблицы выше (`secret put`). Для `SETUP_KEY` придумайте длинную случайную строку из латинских букв и цифр.
4. Подключите бота к воркеру одним запросом (подставьте свои адрес и ключ):

   ```bash
   curl -X POST https://htsd-notify.<имя>.workers.dev/setup -H "X-Setup-Key: <SETUP_KEY>"
   ```

   В ответе будут имя бота и состояние подключения (`last_error` должен быть `null`). Пароль вебхука считается из токена бота, поэтому повторный запуск `/setup` всегда безопасен. После смены `BOT_TOKEN` подождите минуту и запустите его снова.
5. Впишите адрес воркера в `NOTIFY_URL`, а имя бота (без `@`) в `BOT_USERNAME` в `index.html`.
6. Каждый получатель нажимает **Start** в боте, иначе Telegram не даст боту ему писать.

## Если уведомления не приходят

Посмотрите, что видит Telegram:

```bash
curl -X POST https://htsd-notify.<имя>.workers.dev/status -H "X-Setup-Key: <SETUP_KEY>"
```

В ответе важны `webhook.last_error` (последняя ошибка доставки, например `401 Unauthorized`), `webhook.pending` (сколько сообщений ждут доставки) и `recipients` (сколько получателей настроено). Если `last_error` не пустой, выполните `/setup` ещё раз. Учтите: уведомление о тесте приходит только после того, как ученик нажал **Start** в боте.

## Защита

- Запросы от Telegram принимаются только с правильным секретом (`WEBHOOK_SECRET`), иначе ответ 401.
- Кнопки под уведомлением работают только у получателей из `OWNER_CHAT_ID`.
- Заявки с сайта принимаются только с адреса сайта (`ALLOWED_ORIGINS`). Воркер проверяет формат данных и размер запроса, экранирует текст и игнорирует скрытое поле-ловушку для ботов.
- Если кто-то начнёт засыпать бота сообщениями, они будут приходить получателям. Тогда можно добавить защиту (например, Cloudflare Turnstile на сайте).

## Проверка без интернета

```bash
node worker/test.mjs
```

Тест подменяет Telegram заглушкой и проверяет весь путь ученика, обе кнопки, права доступа, ошибки и защиту.
